# Address Book Management System

A **console-based Address Book Management System developed in C**. This project allows users to efficiently manage contact information such as **name, mobile number, and email address**.

## Features

* Add new contacts
* Search contacts by name, mobile number, or email
* Edit existing contacts
* Delete contacts
* Display all contacts
* Sort contacts
* Validate name, mobile number, and email
* Prevent duplicate contacts
* Store contacts permanently using a CSV file
* Load saved contacts when the application starts

## Technologies Used

* C Programming
* Structures
* Functions
* Arrays
* Strings
* File Handling
* CSV File Handling
* Input Validation
* Searching and Sorting
